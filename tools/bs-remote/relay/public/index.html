BS Remote

讓 Claude 遠端操控電腦上的 Beat Saber：移動 Camera2 鏡頭、跳到指定秒數、凍結畫面、截圖或錄影，用來比對網頁版場景燈光。

1. 先裝好這三樣（只要一次）

用 PowerShell 執行：

winget install Python.Python.3.12
winget install Microsoft.DotNet.SDK.8
winget install Gyan.FFmpeg
  • Python：跑接收指令的小程式
  • .NET SDK：在你電腦上編譯 BSRemote mod（遊戲檔案只能在你電腦上編譯）
  • FFmpeg：錄影用，只截圖可以不裝

裝完請關掉 PowerShell 再開一個新的，讓新指令生效。

2. 下載並啟動接收程式

mkdir C:\bsr; cd C:\bsr
iwr https://bs-remote.pages.dev/bsr_agent.py -OutFile bsr_agent.py
python bsr_agent.py --token 你的TOKEN
  • TOKEN 會在對話中給你，第一次輸入後會記在 C:\bsr\bsr_agent.json，之後只要 python bsr_agent.py
  • 它會自動找 Steam 版 Beat Saber 的位置；找不到時加上 --game-dir "D:\...\Beat Saber"
  • 看到「Waiting for commands」就代表連上了，視窗開著就好

3. 接下來都由 Claude 遠端完成

  • 編譯並安裝 BSRemote mod（遊戲要先關掉）
  • 建立一個叫 Remote 的 Camera2 鏡頭（全畫面、隱藏方塊和介面）
  • 用桌面模式（fpfc，不需要頭盔）開遊戲、下載譜面、跳到指定秒數截圖

它只會做固定的幾種動作：開關遊戲、下載譜面到 CustomLevels、寫 Camera2 鏡頭設定、編譯安裝 BSRemote mod、錄影、讀遊戲記錄檔。要停止時在視窗按 Ctrl+C。
