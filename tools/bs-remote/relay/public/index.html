BS Remote

讓 Claude 遠端操控電腦上的 Beat Saber 截圖：用虛擬手把移動 LIV 鏡頭、在指定秒數截圖或錄影，用來比對網頁版場景燈光。

1. 先裝好這些（只要一次）

用 PowerShell 執行：

winget install Python.Python.3.12
winget install Gyan.FFmpeg

裝完關掉 PowerShell 再開一個新的，然後：

pip install vgamepad
  • Python：跑接收指令的小程式
  • FFmpeg：截圖和錄影
  • vgamepad：虛擬 Xbox 手把，用來操控 LIV 的鏡頭（安裝時會一併裝 ViGEmBus 驅動，若跳出安裝視窗請按同意）
  • 選用：用 ModAssistant 裝 DataPuller，可以讀到歌曲目前秒數，就能在指定秒數自動截圖

2. LIV 設定

  • 開 LIV，在 Beat Saber 裡讓 LIV 鏡頭出現（跟平常錄 LIV 一樣）
  • LIV Avatar 介面的 Camera 分頁，把鏡頭模式切到 Gamepad
  • LIV 的輸出視窗保持開著、不要縮到最小（截圖抓的是那個視窗）

3. 下載並啟動接收程式

mkdir C:\bsr; cd C:\bsr
iwr https://bs-remote.pages.dev/bsr_agent.py -OutFile bsr_agent.py
python bsr_agent.py --token 你的TOKEN
  • TOKEN 會在對話中給你，第一次輸入後會記在 C:\bsr\bsr_agent.json，之後只要 python bsr_agent.py
  • 它會自動找 Steam 版 Beat Saber 的位置；找不到時加上 --game-dir "D:\...\Beat Saber"
  • 看到「Waiting for commands」就代表連上了，視窗開著就好

4. 接下來由 Claude 遠端操作

  • 用虛擬手把移動 LIV 鏡頭，截圖確認位置
  • 你開歌（或播放回放）後，在指定秒數自動截圖，或錄一段影片
  • 下載要對照的譜面到 CustomLevels

它只會做固定的幾種動作：截圖／錄影視窗、操作虛擬手把、讀 DataPuller 的歌曲秒數、開關遊戲、下載譜面到 CustomLevels、讀遊戲記錄檔。不會安裝或修改任何 mod。要停止時在視窗按 Ctrl+C。
